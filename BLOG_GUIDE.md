# 📝 Blog Publishing Guide for Claude (Cowork)

This guide explains how to create and publish blog posts on All Things Automated using Cowork.

## Quick Workflow

1. **Write the blog post content** (using Render skill for images)
2. **Create a featured image** with the Render skill
3. **Upload the image to Imgur**
4. **Submit through the admin dashboard** (or email the form data)
5. **Schedule or publish** based on date

---

## Step 1: Use Render Skill to Create Featured Image

When you need a featured image for a blog post:

```
Use the Render skill to create an image for a blog post titled "[TITLE]"
- Topic/subject
- Blog category
- Design should match smart home/automation theme
- Dimensions: 1200x630px (optimal for web)
- Export as high quality PNG
```

After creating the image:
1. Upload it to **Imgur.com** (free, no account needed for basic use)
2. Copy the image URL (format: `https://i.imgur.com/xxxxx.jpg`)
3. Use this URL in the "Featured Image URL" field

## Step 2: Write Blog Content in Markdown

Blog posts are written in **Markdown format**. Here's the structure:

### Basic Markdown Syntax

```markdown
# Main Heading (H1)
## Subheading (H2)
### Sub-subheading (H3)

Paragraph text goes here. You can write naturally.

**Bold text** for emphasis
*Italic text* for subtle emphasis

- Bullet point 1
- Bullet point 2
- Bullet point 3

1. Numbered list item
2. Another item
```

### Example Blog Post Content

```markdown
# Understanding Smart Home Security Systems

Smart home security has evolved dramatically over the last few years. What once required expensive professional installation is now accessible to homeowners everywhere.

## Types of Smart Security

### Cameras & Surveillance
Modern cameras offer features like...

**Key features to look for:**
- 4K resolution
- AI detection
- Cloud storage options
- Local processing

The industry is moving toward AI-powered systems that understand context, not just motion detection.

Learn more by [contacting us](/contact).
```

## Step 3: Fill Out the Admin Form

Navigate to: **https://www.itsallthingsautomated.com/admin**
- Password: `ATA2024!`
- Click the **📝 Blog** tab

### Form Fields

| Field | What to Enter |
|-------|---------------|
| **Title** | Full blog post title (e.g., "5 Ways to Secure Your Smart Home") |
| **Slug** | Auto-generated from title, but you can customize (e.g., "5-ways-secure-smart-home") |
| **Category** | Blog topic (e.g., "Security", "Smart Lighting", "AI & Automation") |
| **Featured Image URL** | Imgur URL from step 1 (e.g., `https://i.imgur.com/xxxxx.jpg`) |
| **Excerpt** | 1-2 sentences summarizing the post (shows on blog listing) |
| **Content** | Full blog post in Markdown format |
| **Status** | Draft / Scheduled / Published |
| **Date** | Publication date |

### Status Options

- **Draft** - Post is saved but not visible to visitors
- **Scheduled** - Post will publish on the specified date
- **Published** - Post is live immediately

## Step 4: Tips for Great Blog Posts

✅ **DO:**
- Write for your target audience (homeowners interested in smart automation)
- Include practical examples and use cases
- Provide actionable advice
- Use clear headings to break up content
- Keep paragraphs short (2-3 sentences)
- Link to related services pages when relevant
- Include a call-to-action at the end (e.g., "Contact us for a consultation")

❌ **DON'T:**
- Write overly technical content without explanation
- Use walls of text without structure
- Forget to include images/visual breaks
- Write promotional content (be genuinely helpful instead)
- Publish without proofreading

## Troubleshooting

**Image URL doesn't work?**
- Verify the Imgur link is correct
- Make sure it's a direct image URL (not a gallery page)
- Try re-uploading to Imgur

**Post isn't showing up?**
- Check that status is "Published" (not Draft)
- Verify the current date is on or after the publish date
- Clear your browser cache
- Check the blog page directly

**Need to edit a post?**
- Go back to the admin dashboard
- Submit the form again with the same slug (it will overwrite)
